# M1 接口、通信与风险说明

## 1. 接口数据

OpenSky 离线接口以 JSON 提供航空状态快照，顶层含批次时间 `time` 与状态数组 `states`。`states` 中每个元素是按 17 个位置索引排列的数组，字段含义见 `opensky_field_dictionary.csv`，核心字段包括 `icao24`、`callsign`、位置/最近联系时间、经纬度、气压/几何高度、`on_ground`、地速、航向与垂直速度。

## 2. 数据形态与封装

原始数组是「每个位置一条记录」的快照，不是完整态势结果：它未按目标聚合、语义未统一、缺少质量标记，当前态势需在接收后按目标保留最新记录生成。发送方必须把含字段名、类型与浮点数的内部结构化记录封装为 41 字节 TeachingLink 帧才能无歧义传输——大端字节序、定点量化、状态/有效性标志与校验和共同构成帧格式。

## 3. 接收校验

接收方依次检查长度、`magic`、`version`、`message_type`、校验和、保留位及标志一致性：长度保证帧完整，头字段保证协议正确，校验和保证传输未损坏，保留位保证符合规范。非法帧记录错误并丢弃，不使程序整体崩溃。

## 4. 持久化角色

CSV 是必做的通用交换格式，便于提交与复查；SQLite 是选做的结构化持久化，可查询并支持 NULL 语义。SQLite 不是前置条件，因为课程成果以离线 CSV 交付为主。

## 5. 工程风险

1. **字段缺失**：无法还原完整记录。用 `validity_flags` 表达空值、占位字节置 0；缺失不得用 0 冒充真实值。
2. **接口延迟**：状态时刻不可用。`time_position` 缺失回退 `last_contact`，两者皆缺记录错误。
3. **消息损坏**：帧不可信。校验和或长度不符判为非法，写入 `validation_log.csv` 并丢弃该帧。
4. **字节序与量化误差**：解码产生偏差。统一大端与量化函数 `Q(y)=floor(y+0.5)`，往返误差不超过一个量化单位。
5. **存储失败**：结果无法落盘。运行前确保 `output/` 目录存在，异常记录不中断。
